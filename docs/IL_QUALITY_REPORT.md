# IL-15B: 配置品質の読み取り専用レポート

`inspectIntelligentLayoutQuality(result, expected)` は現行の成功済み計測IL計画を対象に、revision/fingerprint と本文領域 content を照合し、表示用の診断を返す。計画・保存済みintent・原稿・DOMを変更しない。失敗・旧revision・範囲外矩形等は undefined。呼出元は同一要求世代と実際の本文領域を保証する。任意に編集された計画の完全検証や出版許可ではない。

- 各ページの描画矩形面積率と占有矩形面積率、占有下端、下端から本文領域末尾までの距離、断片数、固定・希望実現・希望未実現数、明示境界を返す。
- 空白ページは番号のみ表示する。固定位置等により意図された空白もあるので、欠陥扱いしない。
- 希望未実現、分割された部品の1計測単位断片を、原稿ID・blockKey・配置ID・単位範囲とともに報告する。単位は必ずしも行ではなく、分割の違反を断定しない。
- ページ分割警告数・既存最適化スコアを表示用の値として返す。面積率は矩形の合計であり、文字のインク面積、外部予約領域、グループ外接矩形内の空白は含まない。合計100%超等は簡易拒否するが独立の衝突検証は行わない。
- O(断片数＋ページ数)。元の計画は変更せず、GUIがユーザーに確認候補を示す用途。保存前の検証と独立印刷検証を置き換えない。

面積、空白ページ、希望未実現、孤立単位、元データ非変更、旧計画・範囲外・競合拒否、最適化スコアの回帰試験を追加。本体への接続・CI・実機は未確認。
