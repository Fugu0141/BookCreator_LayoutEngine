# Layout Engine — 出版面・描画アダプタ契約

状態: 詳細設計ドラフト。アプリ固有のFinalize/保存はBookCreator側。

## 1. 面と番号

表紙/裏表紙は独立の単独ページ。内頁は前付→本文→後付を同一の面系列として交互にleft/right（初期左綴じ）。最初はright既定、left指定可。印刷番号は面判定に使用しない。leftが見開きstart、rightがend。最初のright/最後のleftは相手が欠けてもUI用の空枠だけであり実ページを追加しない。固定見開きは例外で必ず2面を占有。既存計画の論理ページIDを維持して投影する。

番号区間のアンカーは入力の有効な境界、start inclusive/end exclusive。境界がページ途中なら派生改ページ。空白はcountBlankとprintBlank、個別印字上書きを分ける。区間前の面調整空白は前区間に所属するか未割当。番号非表示でも割当ありなら参照・目次の番号を使用可能（書籍設定に従う）。未割当は目次番号空欄。表紙・印刷専用の整合空白には内頁番号を割り当てない。

## 2. 出力投影

digital: 表紙→内頁→裏表紙の単ページ列、面整合だけの実空白を追加しない。
duplex: 出力先の開始面と内頁面を照合、必要な空白を実ページとして追加。例: 表紙右・本文最初右なら表紙裏相当の空白を挿入。終端・抽出範囲・裏表紙の条件を別途検証。冊子面付けではない。出力順はOutputPagePlanで管理し、PagePlanの内頁配置と番号を変えない。本文のみ/表紙のみの抽出も対応し、既存番号を維持。印刷条件変更は利用アプリで再確認。
固定見開きの描画は2面分の幅を持つ共通座標系を左右用紙矩形でクリップ。ベクターや選択可能テキストを目標とし全ページ画像化を既定にしない。綴じ目の安全領域は警告/ガイドでありガイドは出力しない。重要文字の跨ぎ・意図しない欠落を検査。

## 3. 計測・固定描画

HTML/CSS/SVG/ChromiumをPoC候補とする。計測環境fingerprint、フォント実体、画像バイト、CSS・レンダラー版、用紙寸法を固定。表示倍率とDPIは組版単位に影響させない。プレビューと出力は同じ確定PagePlanを利用、独立したページ分割をさせない。ページ単位のDOM/行配置等を組み立て、印刷CSSの違いを制御。固定された矩形だけでなく行折返し・断片の内容・テキストスタイル・描画順を保持する。HTMLの画面表示を正式確認とし、PDFは利用者の出力時のみ生成。HTML描画とPDFで文字組みが一致するかは実測する。

コアはDOM/PDF/ファイルアクセスを必須としない。adapterは能力、環境fingerprint、計測、固定ページ描画を明示する。PDF生成は別adapter/利用側で行う。任意HTML/JSや外部ネットワークにアクセスさせない。資源解決はホストに委ねる。ローカル生成優先、Web正式PDF方式は未確定。

## 4. 検証

PR-01 表紙表示切替と内頁面、PR-02 digital/duplexの順と空白、PR-03 固定見開き分割、PR-04 番号区間と空白、PR-05 HTML/PDFのページ寸法・ページ数・断片位置、PR-06 選択可能テキスト・リンク・埋込フォント、PR-07 フォント差・画像差の検出、PR-08 異なる出力範囲・開始面。実測の許容差やPDF抽出手段はPoCで確定。ページ数だけの一致を十分とみなさない。全て未検証。
